# Fabric Macro-F1 0.80–0.85 Implementation Plan

> **For agentic workers:** Use `superpowers:executing-plans` to implement this plan task by task. Steps use checkboxes for tracking. This document is a plan, not authorization to resume execution after the user's request to plan only.

**Goal:** Improve the existing 24-class fabric classifier to 0.80–0.85 macro F1 on its frozen catalog benchmark, with an honest, separately reported evaluation on independently verified and phone photographs.

**Architecture:** Keep scanner-v8's SigLIP 2 so400m/16 encoder at 384 px and whole-image inference. First establish an exact baseline and test inexpensive changes on cached embeddings. Spend GPU time on noise-aware LoRA training only after a smaller experiment supports it; export a new immutable scanner bundle only after validation and serving checks.

**Tech stack:** Existing Python/PyTorch/timm/scikit-learn/safetensors stack; existing Kaggle accounts for GPU work; CPU-only diagnostics on the Mac. No new model service or paid provider.

**Spec:** The user's 0.80–0.85 target, `docs/handover-2026-10-27.md`, the operational header of `NEXT_SESSION.md`, and `CONTRIBUTING.md`. The latest user instruction is **plan only**.

## Task 2 — Test two bounded, inexpensive improvement routes

**Files/interfaces:** `retrieval_search.py`; `neighbours(reference, query, k, batch_size)`, `vote(similarity, labels, n_classes, temperature)`, and `crossfit_selection(predictions, y, folds, classes, minimum_gain=0.005)`.

- [x] Review the draft against the Task 1 manifest and existing tests. Add a test proving a failed validation gate never evaluates candidate test predictions.
- [x] Use **training images only** as retrieval references. Search exact cosine neighbors in bounded CPU batches. Combine neighbor probabilities with the deployed MLP probabilities; this adds no second encoder.
- [x] Freeze the draft grid before execution: neighbors `{1,5,20,64}`, temperatures `{0.02,0.07}`, class-prior exponents `{0,0.25}`, retrieval weights `{0.1,0.25,0.5,0.75,1}`; always include the unchanged baseline.
- [x] Use deterministic three-fold stratified validation. Each fold's recipe is selected on the other folds. Require pooled out-of-fold macro F1 at least **0.005 above baseline**. The existing encoder/head used this validation previously, so this is a check on the new tuning procedure, not independent evidence of generalization.
- [x] Save the selection and stop in `--mode select`, even if the validation gate passes. Candidate test evaluation belongs to Task 5 after comparing both routes. If rejected, save the rejection and stop this route. Do not broaden the grid after looking at test results.

**Cost control:** CPU-only; no new encoder extraction. If accepted, measure index size and added latency before considering it deployable. Treat >200 ms added median retrieval latency on the Mac as a reason to keep it experimental until optimized and rechecked.

**Outcome (27 Oct):** gate failed — cross-fit macro F1 **0.755992** vs baseline **0.758505** (gain **−0.002513**, required **+0.005**). ## Execution order and stop conditions

1. **First work block:** Task 1 baseline/error report, then Task 2A. This produces evidence without a new GPU training job.
2. **Next GPU block:** Task 2B only, with a small fixed grid. Prepare Task 3's human-review inputs alongside it.
3. **Decision:** If a head-only candidate reaches the target, skip encoder retraining. If none qualifies, use the validation error/label evidence to decide Task 4 versus collecting data.
4. **Final block:** Tasks 5–6. Accuracy improvements do not justify breaking the six dependent heads or the working scanner.

**Do not prioritize now:** Another arbitrary backbone, YOLO/RT-DETR for classification accuracy, repeating crop experiments, a broad ensemble sweep, or deleting all model-disagreed labels. Detection speed is a separate product task.

**No guaranteed score or calendar date:** The sequence is designed to minimize wasted compute and manual work. Reaching 0.80–0.85 remains an empirical result, dependent on data quality, learnable visual distinctions, and the evaluation sample.
