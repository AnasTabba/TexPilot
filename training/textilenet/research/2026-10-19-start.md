Started 2026-10-19 16:01 UTC on Git commit `d6fa46b`. Requested window ends 21:01 UTC. This is an audit and experiment plan, not a claim that training has run.

## Implemented system

- Head A is 27-class fabric structure classification. Head C is a 33-class TextileNet fibre partition collapsed to three trainable families (cellulosic, protein, synthetic). The fourth family, blend, is not trainable from these single-label images. Head B has a four-class treatment taxonomy and hand-labelling tool; the current model bundle path can leave treatment `None`.
- Scanner-v2 uses a shared frozen DINOv2 ViT-B/14 backbone at 224 px. It concatenates CLS and mean patch features, then runs separately fitted linear heads for A and C. Each head is temperature-calibrated and may abstain below its threshold. A fine-tuned Head A can replace the linear structure head in a new immutable bundle, but no such exported model is present here.
- The phone inference path detects a garment, segments/crops views, runs the heads, and compares visual evidence with care-label claims. A failed component records a note and abstains. It does not infer exact fibre composition from RGB images.
- TextileNet acquisition uses the documented 12.8 GB fabric and 14 GB fibre seed archives plus recoverable upstream image manifests. `prepare_data.py` freezes official train/test membership with a stratified 10% validation carve-out and train-side byte-hash deduplication. The training recipe uses pretrained timm backbones, AdamW, warmup/cosine decay, augmentation, mixup/cutmix, EMA, and optional class weighting/sampling. Its current checkpoint and TTA selection metric is validation top-1, while this research brief prioritizes macro F1. Changing that metric needs a separately tagged run, never relabelling the historical baseline.
- Historical catalog-domain results in `docs/results.md` (generated 2026-09-29): frozen DINOv2 probe 74.48 ± 0.03% fabric top-1 across three seeds on n=40,970 test images; scanner-v2 linear Head A top-1 0.744, Head C top-1 0.745 on n=47,805. These numbers are inherited reports, **not reproduced in this run**. `docs/results.md` states that phone-domain evaluation and fine-tuned Head A remain unmeasured. Full TextileNet tables would be in `training/textilenet/results.md`, which is absent in this checkout.
