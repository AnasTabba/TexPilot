# Yarn Factory Management System — Build Kit

Specs to build a digital replacement for the factory's paper registers with Codex or Claude Code.

1. Create an empty project folder and copy these files into it.
2. Add your design templates to `design-templates/`.
3. Open the folder in Codex or Claude Code and paste **Prompt 1** from `KICKOFF-PROMPT.md`.

| File | What it is |
|---|---|
| `AGENTS.md` / `CLAUDE.md` | Rules the coding agent follows (Codex reads AGENTS.md; Claude Code reads CLAUDE.md) |
| `docs/01-PRODUCT-SPEC.md` | What the system does |
| `docs/02-UX-HCI-PRINCIPLES.md` | Usability rules |
| `docs/03-DESIGN-SYSTEM.md` | Look, components, accessibility |
| `docs/04-SCREENS.md` | Every screen |
| `docs/05-EDGE-CASES.md` | What can go wrong and what must happen |
| `docs/06-ARCHITECTURE.md` | Tech stack, database, offline sync, security |
| `docs/07-BUILD-PLAN.md` | Phases and acceptance criteria |
| `KICKOFF-PROMPT.md` | Prompts to paste into the coding tool |
