# Design templates

Put your visual templates here (PNG/JPG screenshots, Figma exports, HTML/CSS, colour palettes,
logo files you own). Suggested names:

- `00-brand.png` (logo, brand colours, fonts if any)
- `01-home.png`, `02-entry-form.png`, `03-register-view.png`, `04-dashboard.png`, ...

The coding agent will extract design tokens from these and apply them to the design system
(see AGENTS.md §5). Templates change the *look*; usability rules in `docs/02-UX-HCI-PRINCIPLES.md`
always stay in force.
