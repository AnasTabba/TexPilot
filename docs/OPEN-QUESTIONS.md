# Before a production build

1. Confirm the factory's legal name, actual users and role permissions, machines, shifts, and opening stock. The current identity and all records are sample data.
2. Confirm the yarn-spec vocabulary, packing tolerances, raw/finished weight sources, loose-cone rules, and mixed-lot allocation.
3. Confirm shift C's business-date cutover, holiday treatment, backdating window and reopening permissions.
4. Select a Pakistan-region API/PostgreSQL host and production identity/OTP provider. Sites currently hosts the private static UI preview only.
5. Review native Urdu wording with real supervisors, and conduct the timed staff usability tests in the build kit.
6. Decide the paper-match print layout and legal delivery-note fields with the factory's actual paper registers.
